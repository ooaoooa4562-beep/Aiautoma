# Telegram AI Assistant v0.1.0

Первая версия AI-ассистента для личного Telegram-профиля через официальный механизм Telegram Business / Chat Automation.

## Важно: правильный способ подключения

Этот проект НЕ использует Telethon и не входит в аккаунт через SMS-код. Он работает как Telegram Bot API business bot: владелец подключает созданного бота к профилю через настройки Telegram Business и выдаёт ему разрешение отвечать в выбранных чатах.

Не отправляйте никому пароль, код входа Telegram или файл сессии. Не добавляйте секреты в GitHub.

## Возможности v0.1.0

- Groq + OpenRouter: основной и резервный AI-провайдер.
- Адаптивный стиль ответов на языке собеседника.
- Отдельная история для каждого диалога (SQLite).
- Только входящие текстовые личные сообщения.
- Не отвечает на группы, каналы, исходящие сообщения и сообщения ботов.
- Защита webhook секретным заголовком.
- По умолчанию `AUTO_REPLY=false` (режим тестирования).
- Автоматическая отправка включается только после проверки.

## 1. Создай Telegram-бота

1. Открой официальный `@BotFather`.
2. Выполни `/newbot`, задай имя и username.
3. Сохрани bot token в секрете. Не публикуй его и не отправляй в чат.
4. Убедись, что в Telegram у аккаунта доступна функция Business / Chat Automation и подключение бота к профилю.

Важно: обычный BotFather-бот сам по себе не читает личные сообщения твоего аккаунта. Нужна именно поддержка Telegram Business и подключение бота к профилю с нужными правами. Если такой настройки в клиенте нет, этот способ пока недоступен для аккаунта.

## 2. Получи ключи моделей

- Groq: https://console.groq.com/keys
- OpenRouter: https://openrouter.ai/keys

Создай ключи и добавь их в переменные Render. У бесплатных тарифов есть лимиты, модели и доступность могут меняться. Не рассчитывай на безлимитную работу.

## 3. Разверни на Render

1. Загрузи файлы проекта в новый GitHub-репозиторий.
2. В Render выбери **New → Blueprint** и подключи репозиторий.
3. Render прочитает `render.yaml`.
4. Добавь значения `TELEGRAM_BOT_TOKEN`, `GROQ_API_KEY`, `OPENROUTER_API_KEY`.
5. Сохрани и дождись успешного деплоя.
6. Скопируй публичный HTTPS URL сервиса, например `https://your-service.onrender.com`.

Blueprint создаёт бесплатный Web Service для проверки webhook. Бесплатный Web Service может засыпать, перезапускаться и не имеет постоянного диска. Поэтому он не гарантирует круглосуточную работу и долговременную SQLite-память. Для постоянной работы нужен подходящий платный постоянно работающий сервис/worker и постоянное хранилище либо внешняя БД.

## 4. Установи webhook

В Render → Environment скопируй `ADMIN_KEY` и `WEBHOOK_SECRET` (не публикуй их).

Выполни запрос к сервису с помощью curl или Postman:

```bash
curl -X POST "https://YOUR-SERVICE.onrender.com/admin/set-webhook" \
  -H "Content-Type: application/json" \
  -H "X-Admin-Key: YOUR_ADMIN_KEY" \
  -d '{"public_url":"https://YOUR-SERVICE.onrender.com"}'
```

Ответ Telegram должен содержать `"ok": true`.

## 5. Сначала тестовый режим

Оставь `AUTO_REPLY=false`. Подключи бота в настройках Telegram Business / Chat Automation, выбери только нужные личные чаты и выдай минимальные разрешения.

На этом этапе приложение получает подходящие сообщения и пишет в логи `DRY RUN`, но не отправляет ответы. Проверь, что webhook работает и бот не обрабатывает неподходящие чаты.

## 6. Включение автоответов

Только после теста и проверки настроек поменяй в Render:

```text
AUTO_REPLY=true
```

Сделай новый deploy. Начни с одного доверенного чата. Сообщи собеседникам, что ответы может готовить AI-ассистент, и не включай автоматические ответы для чувствительных переписок.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от BotFather |
| `WEBHOOK_SECRET` | Проверка подлинности webhook |
| `ADMIN_KEY` | Защита установки webhook |
| `GROQ_API_KEY` | Ключ Groq |
| `OPENROUTER_API_KEY` | Ключ OpenRouter |
| `GROQ_MODEL` | Модель Groq |
| `OPENROUTER_MODEL` | Модель OpenRouter |
| `AI_PROVIDER_ORDER` | Порядок провайдеров |
| `AUTO_REPLY` | `false` для теста, `true` для отправки |
| `MAX_HISTORY` | Число сообщений контекста |

## Ограничения v0.1.0

- Только обычные текстовые личные сообщения.
- Не отвечает на вложения, голосовые, группы и каналы.
- SQLite на бесплатном Render не является постоянным хранилищем.
- Память пока ограничена последними сообщениями каждого диалога.
- Бесплатные AI-планы ограничены по запросам и скорости.
- AI может ошибаться. Не разрешай ему самостоятельно принимать обязательства, раскрывать личные данные или отвечать на финансовые/медицинские/юридические вопросы.

## Локальный запуск для проверки

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

Локально для Telegram webhook нужен публичный HTTPS адрес; для первого запуска можно проверить `/health`.
